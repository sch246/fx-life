# reference/：零件库

`life-prototype.html` 是第一版可玩原型（单文件，内联 CSS 与 JS）。它一开始就把第 1 到第 6 片的系统全部摆出来，所以**只当零件库用**：需要某个零件时读对应段落，按 `src/` 的结构重写搬进来，不要在它基础上删改。

不要从 `src/` 引用这个文件，也不要把它当运行时依赖。

## 要丢掉

- 按钮网格式界面、开局全部可见的状态条和标签页（1406–1803 的渲染层基本都不要）。
- 每 250 毫秒推进 2.5 游戏分钟的时间模型（`STEP_MS`、`MIN_PER_STEP`）。现在是现实 1 秒 = 游戏 1 分钟，见 `src/core/clock.ts`。
- 原型里直接用 `Math.random()`；搬进来时改用 `src/core/rng.ts` 的独立随机流。
- 更早的「稳赢国际」讽刺原型的文案（违反不变量 6）。
